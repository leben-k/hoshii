このフォルダのファイルは、すべて最新です。

■ GitHubに置くファイル（リポジトリのいちばん上に置きます。同じ名前があれば上書き）
  index.html          サイト本体
  build.mjs           検索用のページを作るプログラム
  favicon.svg         アイコン
  favicon-192.png     アイコン
  favicon.ico         アイコン
  apple-touch-icon.png アイコン（スマホのホーム画面用）
  memo.txt            60日に一度、日付を書き換えるメモ

■ GitHubで新しく作るファイル（最初の1回だけ。作成済みなら不要）
  pages.yml           自動更新の指示書
  やり方: GitHubで「Add file → Create new file」を押し、
          ファイル名の欄に  .github/workflows/pages.yml  と入力、
          中身に pages.yml の文章を貼って保存します。

■ GitHubに置かないファイル
  shouhin-list.xlsx   スプレッドシートのひな形（「画像URL」の列を追加しました）。Googleドライブに入れて、Googleスプレッドシートで開きます。

■ 大事な注意
  index.html の中に  const SHEET_CSV_URL = "";  という行があります。
  スプレッドシートのURLを入れたあとで index.html を上書きすると、URLが消えます。
  上書きしたら、もう一度URLを入れてください。

■ スプレッドシートの列（A列から順に）
  番号（自動） / 公開・非公開 / 見出し / 誘導文 / 楽天のコード / 画像URL
  ・楽天のコード … 商品ページへ行くためのリンクのコード
  ・画像URL     … 画像のアドレス、または画像のソースコード
  ・画像のコードに <a href= が入っていれば、「画像URL」だけで足ります。

■ 2026年10月15日の点検で直したこと
  ・スプレッドシートを読めなかったときに、仮の「見出しの例」が表示される不具合を直しました。
  ・読めなかったときは、前回のサイトを残して、作り直しを中止します。

■ 画像が出ないときの点検ページ
  サイトのURLの最後に  #/check  を付けて開きます。
  例: https://leben-k.github.io/hoshii/#/check
  スプレッドシートの各行について、リンクと画像のアドレスが取り出せたか、画像を表示できたかが分かります。
